# 🧠 AI Assistant API

A lightweight backend powered by **FastAPI** and **OpenAI** that takes user input and responds with intelligent, contextual answers. Built to demonstrate real-world skills in Python backend development, API integration, and deploying AI services.

---

## 🚀 Features

- Accepts user queries via a REST API
- Sends input to OpenAI GPT model
- Returns a structured, AI-generated response
- Built with performance and simplicity using FastAPI
- Fully containerized with Docker (optional)
- Ready for deployment

---

## 🛠️ Tech Stack

- **Backend**: [FastAPI](https://fastapi.tiangolo.com/)
- **AI Integration**: [OpenAI API](https://platform.openai.com/)
- **Server**: [Uvicorn](https://www.uvicorn.org/) ASGI server
- **Environment Management**: `.env` + `python-dotenv`
- **Version Control**: Git + GitHub
